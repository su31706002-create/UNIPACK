# UniPack Website Skill

## Mục tiêu
Hỗ trợ AI cập nhật tài liệu và website giới thiệu dự án khởi nghiệp UniPack.

## Trước khi thực hiện
- Đọc README.md để hiểu dự án.
- Đọc index.html để hiểu giao diện hiện tại.
- Xác định rõ nội dung cần thay đổi trước khi chỉnh sửa.

## Quy tắc
- Sử dụng tiếng Việt rõ ràng, dễ hiểu.
- Thiết kế hiện đại, phù hợp với sinh viên.
- Giao diện phải hiển thị tốt trên máy tính và điện thoại.
- Không tự bịa doanh thu, số liệu khảo sát hoặc kết quả kinh doanh.
- Không xóa nội dung đang hoạt động nếu không cần thiết.
- Đảm bảo website tương thích với GitHub Pages.

## Nội dung website
- Giới thiệu dự án UniPack.
- Vấn đề khách hàng và giải pháp.
- Khách hàng mục tiêu.
- Sản phẩm balo dự kiến.
- Mô hình kinh doanh.
- Chiến lược marketing.
- Thành viên nhóm.
- Thông tin liên hệ.

## Quy trình cập nhật
1. Kiểm tra các file hiện có.
2. Xác định mục tiêu cập nhật.
3. Chỉnh sửa nội dung và giao diện phù hợp.
4. Kiểm tra đường dẫn và bố cục.
5. Báo cáo các file đã thay đổi và thông tin còn thiếu.

## Báo cáo kết quả
Sau khi hoàn thành, hãy nêu:
- Những nội dung đã cập nhật.
- Các file đã chỉnh sửa.
- Những lỗi còn tồn tại nếu có.
- Các bước cần làm để xuất bản website.
